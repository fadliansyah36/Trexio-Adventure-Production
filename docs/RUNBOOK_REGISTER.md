# TREXIO INCIDENT RUNBOOK REGISTER

| Runbook ID | Incident Type | Severity | Trigger | Detection Method | Containment Procedure | Recovery Action | Validation Step | Owner Role | Status |
|---|---|---|---|---|---|---|---|---|---|
| `RB-001` | Cloud SQL Connection Loss | P0 | Database connection timeout or socket error | Health Check `/api/health/cloudsql` returns 500 / disconnected | Halt write operations on backend; enable retry mechanism with exponential backoff | Re-establish connection pool from Cloud SQL Auth Proxy / Connector | Execute read/write probe query `SELECT 1` | DBA_ROLE | Active |
| `RB-002` | Schema Drift Detected | P1 | Expected schema table missing from PostgreSQL | Automated Schema Drift Guard (`/api/governance`) returns `DRIFT_DETECTED` | Pause high-risk schema migrations; restrict API endpoint writes to affected table | Re-apply versioned migration script (`src/db/cloudSqlSync.js`) | Verify 12 tables present in `information_schema.tables` | DBA_ROLE | Active |
| `RB-003` | Payment Webhook Delivery Failure | P1 | Midtrans notification failure or duplicate webhook | Payment transaction status mismatch in `payment_transactions` | Queue webhook payload for idempotent retry; isolate duplicate order IDs | Query Midtrans API directly to reconcile status (`settlement`/`expire`) | Confirm `bookings.payment_status = 'paid'` & `paid_at IS NOT NULL` | Backend_Role | Active |
| `RB-004` | Unintended Local JSON Fallback Attempt | P1 | Production code attempting to write to `db.json` | JSON Regression Guard alert | Fail request with HTTP 500; block write to file system | Route operation through PostgreSQL Drizzle/pg repository | Run automated JSON Regression Guard check | Backend_Role | Active |
| `RB-005` | High Slow Query Latency | P2 | PostgreSQL query execution time > 500ms | Query logger latency warning | Isolate affected endpoint; limit pagination page size | Add composite B-tree index on filter/sort columns | Run `EXPLAIN ANALYZE` to verify index scan execution | DBA_ROLE | Active |
| `RB-006` | Ride Capacity Overbooking | P2 | Concurrent join requests exceeding total seats | Transport/Ride seat counter < 0 | Reject overbooking request with atomic transaction rollback | Re-read total seats within `SERIALIZABLE` or `FOR UPDATE` transaction lock | Verify `available_seats >= 0` in `rides` table | Backend_Role | Active |
| `RB-007` | Unauthorized PII Exposure Attempt | P0 | IDOR or unauthenticated request to user contact profiles | API Authorization Middleware rejection | Revoke user session token; block IP address | Audit access logs for affected records; verify RBAC rules | Test authenticated access with non-owner account (expected 403) | Security_Role | Active |
